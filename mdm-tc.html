Castor Managed Device Terms of Use

By enrolling a device into Castor’s device management system you agree that:

  • Castor may manage this device using security tooling such as Microsoft Intune and Microsoft Defender.
  • Device configuration, operating system version, security status and installed applications may be monitored to maintain security and compliance.
  • Castor does not monitor personal content such as files, browsing history, camera or microphone data.
  • Security controls such as disk encryption, security updates and endpoint protection may be enforced.
  • Corporate data must only be accessed using approved applications and services.
  • Castor may remotely remove corporate data or wipe the device if required for security or compliance reasons.
  • Users must follow Castor’s Information Security and Acceptable Use policies when using a managed device.

If you do not agree with these terms, do not enroll the device.
